# Public Demo Data

`public_scoring_demo.csv`는 공개 검토를 위해 만든 **가상·비식별 예시 데이터**입니다.

- 실제 유튜버, 채널, 댓글, 대회 원본 또는 파생 데이터와 관계가 없습니다.
- 값과 `DEMO-*` 식별자는 코드 흐름을 확인하기 위한 예시일 뿐입니다.
- 이 파일로 계산한 score·grade는 실제 프로젝트의 결과, 모델 성능, 등급 기준을 재현하거나 검증하지 않습니다.

공개 실행 경로는 [00_public_scoring_demo.ipynb](../notebooks/00_public_scoring_demo.ipynb)입니다. 실제 프로젝트의 분석 기록과 데이터 공개 경계는 [data/README.md](../data/README.md) 및 [notebooks/README.md](../notebooks/README.md)를 확인하세요.
