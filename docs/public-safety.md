# 공개 안전성 검토

## 공개 기준

이 저장소는 유튜버/인플루언서 협업 리스크 평가 프레임워크를 설명하는 포트폴리오입니다. 개인정보, 원본 크롤링 데이터, 그리고 재배포 조건·식별 가능성 경계가 불명확한 파생 데이터는 공개 대상에서 제외합니다.

## 검토 포인트

- 공개 자료: 문제 정의, 지표 설계, notebook 구현 흐름, 실제 최종 발표자료
- 제외 자료: 원본 댓글 전체, 원본 수집 결과, 파생·집계 데이터 테이블, 모델 가중치, credential, 대회 비공개 자료

## 이력 정리

`data/processed/`는 현재 공개 브랜치와 refs에서 제외합니다. 해당 자료는 로컬 보관이 필요할 수 있으나 `.gitignore`로 계속 제외됩니다. GitHub의 과거 객체 캐시 만료 또는 완전 삭제는 일반 Git push만으로 보장되지 않습니다.

GitHub Support는 역사 재작성 후에도 **민감한 개인정보 또는 구체적 보안 위험이 있는 자료**에 한해 캐시 제거를 지원한다고 안내합니다. 따라서 현재 과거 객체가 남아 있더라도, 실제 민감 정보·보안 위험을 사실대로 설명할 수 없는 경우에는 Support 삭제를 보장된 해결책으로 주장하지 않습니다. 정책과 제출 기준은 [GitHub Support 요청 기준](github-support-purge-request.md)을 확인하세요.

## 리뷰어 안내

평가 대상은 감성, 성장성, 충성도, 업로드 안정성 지표를 리스크 점수로 구조화한 방식입니다. 공개본은 점수 데이터 자체가 아니라 그 설계와 구현 흐름을 검토할 수 있게 합니다. [공개 데모](../notebooks/00_public_scoring_demo.ipynb)는 비식별 가상 입력만으로 계산 연결을 보여 주며, 실제 데이터·성과·등급 기준을 포함하지 않습니다.
