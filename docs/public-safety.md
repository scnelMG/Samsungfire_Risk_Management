# 공개 안전성 검토

## 공개 기준

이 저장소는 유튜버/인플루언서 협업 리스크 평가 프레임워크를 설명하는 포트폴리오입니다. 개인정보, 원본 크롤링 데이터, 그리고 재배포 조건·식별 가능성 경계가 불명확한 파생 데이터는 공개 대상에서 제외합니다.

## 검토 포인트

- 공개 자료: 문제 정의, 지표 설계, notebook 구현 흐름, 실제 최종 발표자료
- 제외 자료: 원본 댓글 전체, 원본 수집 결과, 파생·집계 데이터 테이블, 모델 가중치, credential, 대회 비공개 자료

## 이력 정리

`data/processed/`는 공개 Git 트리와 이력에서 제거합니다. 해당 자료는 로컬 보관이 필요할 수 있으나 `.gitignore`로 계속 제외됩니다. GitHub의 과거 객체 캐시 만료 또는 완전 삭제는 일반 Git push만으로 보장되지 않으므로, 필요하면 GitHub Support의 별도 처리 대상입니다.

## 리뷰어 안내

평가 대상은 감성, 성장성, 충성도, 업로드 안정성 지표를 리스크 점수로 구조화한 방식입니다. 공개본은 점수 데이터 자체가 아니라 그 설계와 구현 흐름을 검토할 수 있게 합니다.
