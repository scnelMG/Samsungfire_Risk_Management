# Historical Modeling Experiments

이 폴더는 경진대회 당시 남긴 예측 모델 탐색 기록을 보존합니다. 공개 포트폴리오의 핵심 성과나 모델 성능 근거로 사용하지 않습니다.

| Notebook | 보존 목적 | 포트폴리오 해석 |
| --- | --- | --- |
| `12_grade_prediction_ml.ipynb` | feature history로 등급을 예측하는 ML 모델 비교 실험 | 원본 데이터와 검증 분할이 공개되지 않아 성능을 인용하지 않습니다. |
| `13_grade_prediction_deep_learning.ipynb` | 시계열 feature를 이용한 LSTM 등급 예측 실험 | validation 설계와 runtime artifact가 재현 경계 밖이므로 성능을 인용하지 않습니다. |

리뷰어는 [분석 방법](../../docs/analysis-method.md), [등급 threshold 설계](../10_grade_threshold_design.ipynb), [최종 등급 부여](../11_grade_assignment.ipynb), 그리고 [실제 최종 발표자료](../../assets/final-presentation.pdf)를 우선 확인해야 합니다.
