# Data

이 디렉터리는 원래 프로젝트의 데이터 작업 위치를 보존하기 위한 안내 문서만 공개합니다.

## 공개 정책

이 저장소에는 원본 데이터뿐 아니라 파생 데이터 테이블과 중간 산출물도 포함하지 않습니다. 채널·영상 단위의 상세 값은 집계 결과처럼 보여도 재배포 조건, 수집 시점, 식별 가능성 경계를 이 저장소만으로 검증할 수 없기 때문입니다.

## 분석에서 사용한 개념

| 개념 | 설명 |
| --- | --- |
| 인지도 | 조회수·구독자 등 공개 규모 신호 |
| 성장성 | 월별 성과 또는 구독자 관련 변화 신호 |
| 감성 | 댓글 반응을 모델로 변환한 score |
| 충성도 | 반복적·안정적 참여를 나타내는 대리 지표 |
| 업로드 안정성 | 영상 간격과 업로드 cadence 신호 |
| 등급 | 여러 score를 threshold로 요약한 사람이 읽기 쉬운 결과 |

세부 컬럼과 notebook 단계는 [분석 방법](../docs/analysis-method.md) 및 [notebook 안내](../notebooks/README.md)에서 확인할 수 있습니다. 로컬 보관본은 Git이 무시하며, 이 저장소의 공개본에 다시 추가하지 않습니다.
