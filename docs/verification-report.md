## 남은 주의 사항

과거 객체의 GitHub 캐시 완전 제거는 일반적인 force-push만으로 보장되지 않습니다. 민감하거나 재배포 제한이 있는 자료가 과거 커밋 SHA로 계속 접근될 경우 GitHub Support에 purge를 요청해야 합니다.
